About WebRTC connections

With WebRTC, browsers connect to each other directly. They find each other through this page's server, if it helps with that, or else through public BitTorrent trackers and Nostr relays. Players connected this way can see each other's IP addresses.

The demo is downloaded with WebTorrent: from other players who have this page open, and from this site. While you play, your browser shares the demo with other players in turn (at most 1 MB/s).

Network games (Network → Start in the game's menu): the player who starts one gets a room code and a link to send to the others. Their browsers connect with WebRTC, and also through this page's server if it can pass games on, which then covers browsers and networks that WebRTC doesn't get through.

WebRTC works when the page is opened over https (or on localhost): browsers only offer the cryptography it needs there. Elsewhere, e.g. from a computer on your local network, the demo comes from this site only, and network games go through this page's server, if it can pass them on.

No WebRTC doesn't connect to other players' browsers: the demo comes from this site, and network games go through this page's server (only possible if it can pass games on).

What is shared: only the files of the official Serious Sam: The First Encounter demo (2001), which, to our knowledge, is freely redistributable. It is the same demo that was given away on magazine discs and download sites and that the Internet Archive hosts today. Nothing else is ever shared: game files from your own installation, your settings and your saved games stay on your device.
